學習提示

認識 Seeed XIAO Esp32-S3 開發板

先來認識這塊開發板上的兩個重要按鈕。

面向板子正面（USB 接口朝上）時：

  • 左邊為 REST（重開機）按鈕：重新啟動。
  • 右邊為 BOOT 按鈕：主要用於進入燒錄（bootloader）模式。

下載並安裝 Thonny

  • Thonny 是一款非常適合初學者的 MicroPython 開發環境。
  • 請前往官方網站下載並安裝：https://thonny.org

ESP32-S3 連接電腦

使用 USB 傳輸線將 ESP32-S3 開發板連接到電腦。

Thonny 設定路徑：
工具 → 選項 → 直譯器 → Thonny應該要用哪一種直譯器執行你的程式? → 選擇 MicroPython (ESP32)

請注意「選擇連接埠或是 WebREPL」的顯示狀態：

如果顯示為 Board CDC，代表目前不是燒錄模式。(如下圖)
  • 要進入燒錄模式，可依以下步驟操作：
    1. 第一種，官網寫的方式是按住 BOOT 按鈕不放，然後接上USB線。
    2. 第二種，右手按住 BOOT 按鈕不放，左手再按一下 RESET 按鈕後放開，最後放開 BOOT 按鈕。
  • 按鈕會有清楚的「喀」一聲，正常使用不會按壞
顯示為 Serial debug unit，才是燒錄模式。(如下圖)

燒錄 MicroPython 韌體

依照下圖的設定，將 MicroPython 韌體燒錄至開發板中。

  1. 安裝或是更新MicroPython。

  2. MicroPython family選擇ESP32-S3
  3. variant選擇Espressif ESP32-S3
  4. version選擇1.27.0
    5. 燒錄完成， 務必要回到正常模式。
    1. 可以按一下Esp32板子上的Rest按鈕。
    2. 工具列的執行 → 設定直譯器 → 直譯器 → 選擇連接埠或是WebREPL → 選擇Board CDC @ COM → 按下確認。
    3. 如果Thonny左下窗格沒出現MicroPython設備跟boot.py，再按一下重新啟動。

Thonny簡易操作步驟

  1. 插上Esp32，打開Thonny軟體。正常的畫面如下，互動環境有MicroPython的訊息，左下窗格有看到MicroPython 設備。

  2. 工具列　-> 選項 -> 一般。
    • 僅允許單個Thonny實例，有勾只能操作一個Esp32，不勾選可以操作多個Esp32。
    • 使用介面模式，選expert。
    • 使用介面的縮放倍數，選1.5或2.0。
    • 字體縮放模式，選automatic。

  3. 檔案，這窗格是顯示電腦的檔案。通常只會用到一個功能，按右鍵選上傳到 /，把檔案傳輸到Esp32。

  4. MicroPython 設備，這窗格是顯示Esp32的檔案。通常只會用到一個功能，按右鍵選建立新檔。
    建立py檔務必含同副檔名，例如test.py

  5. 未命名的檔案，直接按打叉的地方關掉。

  6. boot.py左鍵點兩下，輸入print("hello world")
    7. boot.py裡面不要使用while迴圈，會無法再進入Thonny編輯，一通電就卡在迴圈裡。

  7. 按下執行目前腳本。
    • 互動環境出現兩次hello world，boot.py一通電就會執行第1次，接著會再執行1次。
    • 每次開機，boot.py一定先跑，接著跑main.py。

boot.py適合做這些事情

  • 📶 WiFi 連線（STA / AP）
  • 🕰 設定 RTC / 時區
  • 📂 掛載 SD 卡
  • 🔐 設定系統參數
  • 🔇 關閉除錯輸出
  • 🧹 只做一次的初始化

main.py適合做這些事情

  • 🌡 讀 DHT22 / SHT31
  • 📺 OLED 顯示
  • 🌐 HTTP Server
  • ☁️ ThingSpeak 上傳
  • 🔁 while True 主迴圈
