擴充板D1按鈕控制 User LED

需要的材料

  • Seeed XIAO Esp32-S3開發板1片。
  • Seeeduino XIAO Expansion Board擴充板1片。

認識 Seeeduino XIAO Expansion Board擴充板

在開始撰寫程式之前，先來認識這塊擴充板。

  • D1按鈕
  • 無源蜂鳴器
  • 0.96" OLED 顯示模組
  • MicroSD 卡插槽
  • RTC 電池座

開啟 Thonny 並執行範例程式

UserButton.py

⚠️ 程式為無限迴圈執行，
若要停止程式，請在Thonny 連按兩次 Ctrl + C 
from machine import Pin
import time

# ========= 開發板說明 =========
# 適用 XIAO ESP32S3 + Expansion Board Base for XIAO
# User LED 為低電位點亮（Active LOW）

# =====================
# 設定 User LED（GPIO21）
# =====================
UserLed = Pin(21, Pin.OUT)

# =====================
# 設定 D1 按鈕（GPIO2，使用內建上拉）
# =====================
Button_D1 = Pin(2, Pin.IN, Pin.PULL_UP)

def 打開UserLed():
    # 低電位 → LED 亮
    UserLed.value(0)

def 關掉UserLed():
    # 高電位 → LED 滅
    UserLed.value(1)

# 開機先關燈
關掉UserLed()

# 主迴圈：持續讀取按鈕狀態
while True:
    if Button_D1.value() == 0:   # 按鈕被按下
        打開UserLed()
    else:                        # 按鈕放開
        關掉UserLed()

    time.sleep(0.01)             # 簡單消抖

▶ 執行結果

  • 按下 D1 按鈕 → User LED 亮
  • 放開 D1 按鈕 → User LED 滅
