開啟 Thonny 並執行範例程式

⚠️ 程式為無限迴圈執行，
若要停止程式，請在Thonny 連按兩次 Ctrl + C

YsIrtmReceiver.py


from machine import UART, Pin       # 匯入 UART 與 Pin
import time                         # 匯入時間模組

# ======== UART 設定 (TX=9, RX=8, 9600 bps) ========
uart = UART(2, baudrate=9600, tx=9, rx=8)  
# TX(GIPO 9) → RXD(YS-IRTM)、RX(GIPO 8) → TXD(YS-IRTM)

# 儲存接收到的 IR 訊號
ir_codes = []

print("開始接收紅外線訊號...按 Ctrl+C 停止接收")

try:
    while True:
        if uart.any():                # UART 緩衝區有資料
            data = uart.read()        # 讀取資料
            if data:
                code = data.hex()     # 將 bytes 轉成 hex 字串
                print("接收到 IR code:", code)
                ir_codes.append(code) # 儲存訊號
        time.sleep(0.05)              # 延遲 50ms

except KeyboardInterrupt:             # 按 Ctrl+C 停止
    print("接收結束，共儲存", len(ir_codes), "筆訊號")

# ======== 發射儲存的 IR 訊號 ========
print("開始發射儲存的紅外線訊號...")
for code in ir_codes:
    uart.write(bytes.fromhex(code))    # 將 hex 字串轉回 bytes 並發射
    print("已發射:", code)
    time.sleep(0.5)                    # 每筆訊號間隔 0.5 秒

print("全部訊號發射完成")

⚠ 注意事項

  • 該模組主要用在NEC協議的遙控。
  • TX/RX 接線一定要反過來，否則無法收發
  • 不同遙控器的訊號編碼不同，本範例只示範重發已接收訊號
  • 發射紅外線時請勿對著眼睛

▶ 執行結果

  • 接收時，終端機會顯示每筆紅外線訊號的 hex code，例：09f645，不足6碼的或空字串的應該不是NEC協議的遙控。
  • 按 Ctrl+C 結束接收。
  • 程式會將接收的訊號依序發射。
