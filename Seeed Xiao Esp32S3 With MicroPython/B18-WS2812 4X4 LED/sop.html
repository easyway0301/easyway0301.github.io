WS2812 RGB LED

需要的材料

  • Seeed XIAO Esp32-S3 開發板1片。
  • 麵包板1片。
  • WS2812 RGB LED 1個。

腳位圖

圖片來源： Seeed Studio 官方文件

接線圖

  • 把Esp32插在麵包板左側正中間。
  • Esp32的GND接在模組的GND。
  • Esp32的3V3接在模組的VCC。
  • Esp32的GPIO 9接在模組的IN。

開啟 Thonny 並執行範例程式

Ws2812Led4x4.py

from machine import Pin
import neopixel
import time

# ========= WS2812 設定 =========
# 資料線接在 GPIO 9
pin = Pin(9, Pin.OUT)

# 建立 NeoPixel 物件（4 顆 LED）
np = neopixel.NeoPixel(pin, 4)

# 逐顆點亮藍色 LED
for i in range(4):
    np.fill((0, 0, 0))    # 全部熄滅
    np[i] = (0, 0, 255)  # 第 i 顆顯示藍色
    np.write()           # 將資料送出
    time.sleep(0.3)      # 停留 0.3 秒

# 全部關閉
np.fill((0, 0, 0))
np.write()

⚠ 注意事項

  • WS2812 對電壓與訊號品質較敏感，請確保接線穩定。
  • 顆數多或亮度高時請使用外接電源。
  • 若 LED 不亮，請確認顆數設定是否正確。

▶ 執行結果

4 顆 WS2812 LED 會依序亮起藍色燈， 最後全部熄滅。
