Seeed Xiao Esp32S3 && ESP32 AP模式

需要的材料

  • Seeed XIAO Esp32-S3 開發板1片。

認識 ESP32-S3 開發板

讓 ESP32 啟動 AP 模式（基地台）， 並建立一個簡單的 HTTP Server。

  • ESP32 自行開 Wi-Fi 熱點
  • 手機 / 電腦可直接連線
  • 瀏覽器輸入 IP 即可看到回應
✔ 不需要外部路由器，也能直接連 ESP32
  • SSID：ESP32_AP
  • 密碼：12345678
  • 連線後 IP：通常為192.168.4.1
📌 密碼長度必須至少 8 個字元，否則 AP 會啟動失敗

開啟 Thonny 並執行範例程式

⚠️ 程式為無限迴圈執行，
若要停止程式，請在Thonny 連按兩次 Ctrl + C 

import network              # 匯入 network 模組，用來控制 ESP32 的 Wi-Fi（AP / STA）
import socket               # 匯入 socket 模組，用來建立 TCP / HTTP 伺服器
import time                 # 匯入 time 模組（本範例雖未使用，通常用於延遲或時間控制）

# ---------- AP 設定 ----------
SSID = "ESP32_AP"            # 設定 AP（基地台）的 Wi-Fi 名稱
PASSWORD = "12345678"        # 設定 AP 的連線密碼（至少 8 碼）

ap = network.WLAN(network.AP_IF)  # 建立一個 AP 模式的 WLAN 物件

if ap.active():              # 檢查目前 AP 是否已經啟用
    ap.active(False)         # 如果已啟用，先關閉舊的 AP
    print("已停掉舊的 AP")   # 印出提示訊息

ap.active(True)              # 啟用 AP 模式
ap.config(                   # 設定 AP 相關參數
    essid=SSID,              # 設定 Wi-Fi 的 SSID 名稱
    password=PASSWORD,       # 設定 Wi-Fi 密碼
    authmode=3               # 設定加密模式（3 = WPA2-PSK）
)

print("AP 已啟動")           # 顯示 AP 已成功啟動
print("SSID:", SSID)         # 顯示 AP 的 Wi-Fi 名稱
print("密碼:", PASSWORD)     # 顯示 AP 的 Wi-Fi 密碼
print("IP:", ap.ifconfig()[0])  # 顯示 AP 的 IP 位址（通常是 192.168.4.1）

addr = socket.getaddrinfo(   # 取得本機位址資訊
    "0.0.0.0",               # 監聽所有網路介面
    80                       # 使用 HTTP 標準的 80 Port
)[0][-1]                     # 取出 socket 可用的位址格式

s = socket.socket()          # 建立一個 TCP Socket 物件
s.setsockopt(                # 設定 socket 選項
    socket.SOL_SOCKET,       # 指定 socket 層級
    socket.SO_REUSEADDR,     # 允許重複使用位址
    1                        # 啟用該選項
)
s.bind(addr)                 # 將 socket 綁定到指定的 IP 與 Port
s.listen(1)                  # 開始監聽連線（最多 1 個等待佇列）

print("TCP Server 已建立，port 80")  # 顯示 TCP Server 已啟動

try:
    while True:              # 進入無限迴圈，持續等待客戶端連線
        cl, addr = s.accept()# 接受客戶端連線，cl 是連線物件，addr 是客戶端位址
        print("Client 連線:", addr)  # 印出客戶端的 IP 與 Port

        data = cl.recv(1024).decode()  # 接收最多 1024 bytes 的資料並轉成字串
        print("收到:", data)           # 印出接收到的 HTTP 請求內容

        cl.send(                       # 回傳 HTTP 回應給客戶端
            "HTTP/1.1 200 OK\r\n\r\nHello ESP32"
        )
        cl.close()                     # 關閉此次客戶端連線

except KeyboardInterrupt:    # 當按下 Ctrl + C 時觸發
    print("停止 Server")     # 印出 Server 停止訊息

finally:
    s.close()                # 關閉 socket 釋放資源
    ap.active(False)         # 關閉 AP 模式

🧪 測試方式

  1. 燒錄程式到 ESP32
  2. 手機 / 電腦連線到 ESP32_AP
  3. 打開瀏覽器，輸入：http://192.168.4.1
  4. 畫面出現 Hello ESP32 即成功
⚠ 若重新燒錄失敗，請確認 Port 80 是否被其他程式佔用
