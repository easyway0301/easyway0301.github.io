User LED 控制

需要的材料

  • Seeed XIAO Esp32-S3 開發板1片。

認識 ESP32-S3 開發板

在開始撰寫程式之前，先來認識這塊開發板上的 User LED。

方向說明：
面向板子正面（USB Type-C 接口朝上）時，
  • User LED 位於 BOOT 按鈕下方。
  • User LED GPIO在21。
  • 亮起時為黃色。

正面圖

圖片來源： Seeed Studio 官方文件

開啟 Thonny 並執行範例程式

以下範例為控制 Xiao Ese32-S3 上的 User LED。 


from machine import Pin
import time

# 本範例適用：Seeed XIAO ESP32-S3 開發板
# TYPE-C 插頭朝上時，User LED 位於右側
# LED 亮燈時為「黃色」

# 設定 LED 腳位（GPIO 21）
UserLed = Pin(21, Pin.OUT)

def 打開UserLed():
    print("打開 UserLed")
    UserLed.value(0)  # 低電位亮燈

def 關掉UserLed():
    print("關掉 UserLed")
    UserLed.value(1)  # 高電位熄燈

打開UserLed()
print("暫停 2 秒")
time.sleep(2)
關掉UserLed()

▶ 執行結果

打開UserLed，暫停2秒，關掉UserLed。
