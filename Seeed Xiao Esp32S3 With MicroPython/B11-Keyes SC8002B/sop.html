SC8002B 蜂鳴器

第一步：模組介紹

SC8002B 蜂鳴器是一種可由 PWM 控制音高的模組， 可播放音符與簡單旋律，但無法直接唸中文。

📌 注意事項：
• MicroPython 官方不支援直接播放 MP3
• 若要播放 MP3，需要使用 uPyAudio 或 mp3dec
• 本範例示範最簡單的音符播放

接線方式 (Seeed XIAO ESP32-S3)：

  • Buzzer IN → GPIO 9
  • VCC → 3V3
  • GND → GND
圖片來源： Seeed Studio 官方文件

第二步：MicroPython 程式碼

以下程式碼可在 Thonny 上執行，播放簡單旋律。


from machine import Pin, PWM        # 匯入 Pin 與 PWM 類別
import time                         # 匯入時間模組

# === 初始化 PWM ===
buzzer = PWM(Pin(9))                # 將 GPIO9 設為 PWM 輸出腳位

# === 定義音階頻率 (Hz) ===
notes = {
    'C4': 262,                      # C4
    'D4': 294,                      # D4
    'E4': 330,                      # E4
    'F4': 349,                      # F4
    'G4': 392,                      # G4
    'A4': 440,                      # A4
    'B4': 494,                      # B4
    'C5': 523                       # C5
}

# === 定義旋律 ===
melody = [
    'C4', 'E4', 'G4', 'C5',         # 前半段
    'C5', 'G4', 'E4', 'C4'          # 後半段
]

duration = 0.3                       # 每個音符長度 0.3 秒

# === 播放旋律 ===
for note in melody:                   # 遍歷旋律中的每個音符
    freq = notes[note]                # 取得音符對應頻率
    buzzer.freq(freq)                 # 設定 PWM 頻率
    buzzer.duty_u16(32768)            # 設定 50% 音量
    time.sleep(duration)              # 播放音符時間

# === 停止 PWM ===
buzzer.deinit()                       # 釋放 PWM，停止發聲

執行結果

  • 蜂鳴器播放簡單旋律
  • 音量可透過 duty_u16 調整
  • 可延伸成多音符播放或簡單音樂播放程式
