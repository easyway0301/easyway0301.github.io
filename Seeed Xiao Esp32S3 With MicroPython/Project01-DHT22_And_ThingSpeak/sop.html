ThingSpeak SOP 教學

適用平台：ESP32 / ESP32-S3 / MicroPython

一、目的說明

本 SOP 用於說明如何使用 ThingSpeak 平台，將 ESP32 感測資料上傳至雲端， 並可再從雲端讀取或下載資料，適合作為教學、實驗與專題展示。

  • 建立 ThingSpeak Channel
  • ESP32 上傳感測資料
  • 讀取 / 下載雲端資料
  • 瞭解免費版容量限制

二、ThingSpeak 平台簡介

ThingSpeak 是 MathWorks 提供的 IoT 雲端資料平台， 設計理念為 「以數值型資料為主」。

  • 使用 HTTP / HTTPS 傳輸
  • 支援 JSON / CSV 資料格式
  • 內建即時圖表（Charts）

三、免費版限制（重要）

項目 免費版限制
Channel 數量 4 個
每 Channel 欄位 8 個（Field1 ~ Field8）
最短更新間隔 15 秒
每年上傳筆數 約 3,000,000 筆（帳號共用）
免費版若更新間隔小於 15 秒，資料將無法成功寫入。

四、建立 Channel 步驟

  1. 登入 ThingSpeak（https://thingspeak.com）
  2. 點選 Channels → New Channel
  3. 設定 Channel Name 與 Field 名稱
  4. 儲存後取得 Channel ID 與 API Keys

五、可傳送的資料格式

1. Field（主要資料）

  • 僅支援數值（整數 / 浮點數）
  • 不可傳送文字或 JSON
field1=25.6
field2=80

2. Status（狀態文字）

Status 可傳送簡短文字（中文 / 英文），僅供顯示使用，無法用於圖表。 

status=系統正常
建議將「狀態」轉為數值代碼，存入 Field 欄位中。

六、ESP32 上傳資料（MicroPython 範例）

import urequests
import time

API_KEY = "你的 Write API Key"

while True:
    temp = 26.3
    hum = 78

    url = (
        "https://api.thingspeak.com/update?"
        "api_key={}&field1={}&field2={}&status={}"
    ).format(API_KEY, temp, hum, "正常")

    r = urequests.get(url)
    r.close()

    time.sleep(15)   # 免費版最短 15 秒

七、資料讀取與下載

1. CSV 下載（Excel 可直接開啟）

https://api.thingspeak.com/channels/你的ChannelID/feeds.csv

2. JSON 讀取（程式使用）

https://api.thingspeak.com/channels/你的ChannelID/feeds.json

3. 只讀取最新一筆資料

https://api.thingspeak.com/channels/你的ChannelID/feeds/last.json

八、ESP32 讀取資料範例（MicroPython）

import urequests

CHANNEL_ID = "123456"
READ_KEY = "你的 Read API Key"

url = "https://api.thingspeak.com/channels/{}/feeds/last.json?api_key={}".format(
    CHANNEL_ID, READ_KEY)

r = urequests.get(url)
data = r.json()
r.close()

print("Temperature:", data["field1"])
print("Humidity:", data["field2"])

九、常見注意事項

  • Field 欄位只能存數值
  • 免費版更新間隔至少 15 秒
  • 大量資料建議定期匯出 CSV 備份

十、結語

ThingSpeak 非常適合作為 IoT 教學與入門雲端平台， 只要遵守 數值為主、更新頻率控制 的原則， 即可穩定且免費地長期使用。
