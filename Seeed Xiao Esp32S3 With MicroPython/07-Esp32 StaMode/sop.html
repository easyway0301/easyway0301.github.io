Seeed Xiao Esp32S3 && ESP32 Wi-Fi Station 模式

需要的材料

  • Seeed XIAO Esp32-S3 開發板1片。

認識 ESP32-S3 開發板

使用ESP32-S3 作為 Wi-Fi Station（STA）模式，連接到既有的無線網路。

⚠️ 你需要知道要連接的 SSID（熱點名稱）與密碼
📌 若無法連線，請確認 Wi-Fi SSID 及密碼正確、Wi-Fi 訊號良好。

📶 Wi-Fi 設定參數

  • SSID：你的無線網路名稱
  • Password：你的 Wi-Fi 密碼

開啟 Thonny 並執行範例程式


import network        # 引用 Wi-Fi 模組
import time

# 你的熱點 SSID 與密碼
SSID = "YourSSID"
PASSWORD = "YourPassword"

# 建立 Station 介面
sta = network.WLAN(network.STA_IF)

# 啟動 Station
sta.active(True)

# 連接 Wi-Fi
print("📶 開始連線到 Wi-Fi:", SSID)
sta.connect(SSID, PASSWORD)

# 等待連線結果，最多等 10 秒
timeout = 10
while timeout > 0 and not sta.isconnected():
    print("⏳ 連線中…", timeout)
    time.sleep(1)
    timeout -= 1

# 判斷是否連線成功
if sta.isconnected():
    print("✅ Wi-Fi 連線成功！")
    print("📍 IP 位址:", sta.ifconfig()[0])
else:
    print("❌ Wi-Fi 連線失敗")

▶ 執行結果

若成功連上 Wi-Fi，你會在序列埠看到類似：

  • 📶 開始連線…
  • ✅ Wi-Fi 連線成功！
  • 📍 IP 位址: 192.168.1.xxx

若沒成功連線會顯示 ❌ Wi-Fi 連線失敗。
