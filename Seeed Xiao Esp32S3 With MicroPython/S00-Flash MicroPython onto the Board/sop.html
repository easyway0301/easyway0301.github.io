下載Thonny及燒錄韌體

需要的材料

  • Seeed XIAO Esp32-S3 Sense開發板1片。

認識 Seeed XIAO Esp32-S3 Sense開發板

先來認識這塊開發板上的兩個重要按鈕。

面向板子正面（USB 接口朝上）時：

  • 左邊為 REST（重開機）按鈕：重新啟動。
  • 右邊為 BOOT 按鈕：主要用於進入燒錄（bootloader）模式。

下載並安裝 Thonny

  • Thonny 是一款非常適合初學者的 MicroPython 開發環境。
  • 請前往官方網站下載並安裝：https://thonny.org

下載韌體

  • Esp32 Sense需要下載OV3660鏡頭的韌體安裝。
  • 請前往cnadler86的Github下載並安裝：cnadler86的Github
  • 務必下載v0.6.0 (mpy 1.27.x)的mpy_cam-v1.27.0-XIAO_ESP32S3.zip ，不要用最新版。(最新版語法有點修改)
  • 找到v0.6.0 (mpy 1.27.x)後，點一下Assets，mpy_cam-v1.27.0-XIAO_ESP32S3.zip在最下面。
  • 解壓縮後，會有檔案firmware.bin。

ESP32-S3 Sense連接電腦

使用 USB 傳輸線將 ESP32-S3 Sense開發板連接到電腦。

Thonny 設定路徑：
工具 → 選項 → 直譯器 → Thonny應該要用哪一種直譯器執行你的程式? → 選擇 MicroPython (ESP32)

請注意「選擇連接埠或是 WebREPL」的顯示狀態：

如果顯示為 Board CDC，代表目前不是燒錄模式。(如下圖)
  • 要進入燒錄模式，可依以下步驟操作：
    1. 第一種，官網寫的方式是按住 BOOT 按鈕不放，然後接上USB線。
    2. 第二種，右手按住 BOOT 按鈕不放，左手再按一下 RESET 按鈕後放開，最後放開 BOOT 按鈕。
  • 按鈕會有清楚的「喀」一聲，正常使用不會按壞
顯示為 Serial debug unit，才是燒錄模式。(如下圖)

燒錄 MicroPython 韌體

依照下圖的設定，將 MicroPython 韌體燒錄至開發板中。

  1. 安裝或是更新MicroPython。

  2. 選Select local MicroPython Image。

  3. 安裝。
    4. 燒錄完成， 務必要回到正常模式。
    1. 按一下Esp32板子上的Rest按鈕。
    2. 工具列的執行 → 設定直譯器 → 直譯器 → 選擇連接埠或是WebREPL → 選擇Board CDC @ COM → 按下確認。
    3. 如果Thonny左下窗格沒出現MicroPython設備跟boot.py，再按一下重新啟動。
