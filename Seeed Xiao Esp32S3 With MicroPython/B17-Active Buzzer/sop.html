Seeed Xiao Esp32-S3 && MicroPython && Active Buzzer 有源蜂鳴器

需要的材料

  • Seeed XIAO Esp32-S3 開發板1片。
  • 麵包板1片。
  • 有源蜂鳴器1個。

腳位圖

圖片來源： Seeed Studio 官方文件

接線圖

  • 把Esp32插在麵包板左側正中間。
  • Esp32的GND接在模組的-。
  • Esp32的GPIO 9接在模組的+。

開啟 Thonny 並執行範例程式

ActiveBuzzer.py

from machine import Pin
import time

# ========= 有源蜂鳴器設定 =========
# 蜂鳴器正極接 GPIO 9，負極接 GND
buzzer = Pin(9, Pin.OUT)

# 重複鳴叫 10 次
for i in range(10):
    buzzer.value(1)      # 開啟蜂鳴器（發聲）
    time.sleep(0.2)      # 發聲 0.2 秒
    buzzer.value(0)      # 關閉蜂鳴器
    time.sleep(0.2)      # 停止 0.2 秒

⚠ 注意事項

  • 此範例僅適用於「有源蜂鳴器」。
  • 有源蜂鳴器與無源蜂鳴器不同。
  • 請確認接線極性，避免長時間高電位造成損壞。

▶ 執行結果

蜂鳴器會以「嗶－嗶－」的方式響 10 次， 每次發聲 0.2 秒、停止 0.2 秒。
