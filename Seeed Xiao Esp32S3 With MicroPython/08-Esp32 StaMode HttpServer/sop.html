Wi-Fi HTTP Server (UserLed 控制)

需要的材料

  • Seeed XIAO Esp32-S3 開發板1片。

認識 ESP32-S3 開發板

ESP32‑S3 以 Wi-Fi Station 模式連線，並建立 HTTP Server 控制板上的 UserLed。

  • 連接你的 Wi-Fi 網路
  • 建立 HTTP Server，監聽 Port 80
  • 透過瀏覽器或網頁請求控制 UserLed 開關
✔ 適合初學 MicroPython & ESP32 的 IoT 範例

開啟 Thonny 並執行範例程式

import network
import socket
import time
from machine import Pin

# ===== Wi-Fi 設定 =====
SSID = "你的WiFi名稱"
PASSWORD = "你的WiFi密碼"

# 啟動 STA
sta = network.WLAN(network.STA_IF)
sta.active(True)
sta.connect(SSID, PASSWORD)

# 等待連線
while not sta.isconnected():
    time.sleep(1)

ip = sta.ifconfig()[0]
print("IP:", ip)

# ===== HTTP Server =====
addr = socket.getaddrinfo("0.0.0.0", 80)[0][-1]
s = socket.socket()
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
s.bind(addr)
s.listen(1)

# ===== 控制 UserLed =====
UserLed = Pin(21, Pin.OUT)

def 打開UserLed():
    print("打開UserLed")
    UserLed.value(0)

def 關掉UserLed():
    print("關掉UserLed")
    UserLed.value(1)

print("HTTP Server Ready")
print("打開UserLed：http://" + ip + "/turnOn")
print("關掉UserLed：http://" + ip + "/turnOff")

while True:
    cl, addr = s.accept()
    print("Client:", addr)
    req = cl.recv(1024).decode()
    print("REQ:")
    print(req)

    if "GET /turnOn " in req:
        打開UserLed()
        response = "HTTP/1.1 200 OK\r\nContent-Type: text/html; charset=utf-8\r\n\r\n打開UserLed OK"

    if "GET /turnOff " in req:
        關掉UserLed()
        response = "HTTP/1.1 200 OK\r\nContent-Type: text/html; charset=utf-8\r\n\r\n關掉UserLed OK"

    cl.send(response.encode())
    cl.close()

🧪 測試方式

  1. 將程式上傳至 ESP32-S3
  2. 透過序列埠查看印出的 IP
  3. ✅ Wi-Fi 連線成功！
  4. 📍 IP 位址：10.0.4.33
  5. 瀏覽器輸入 http://10.0.4.33/turnOn
  6. 瀏覽器輸入 http://10.0.4.33/turnOff
  7. LED 亮／滅表示操作成功
📌 若無法控制 LED，請確認 Wi-Fi 名稱及密碼正確

⚠ 注意事項

  • UserLed 為板上預設 LED（GPIO21）
  • Server 需可接受外部連線
  • 避免將密碼寫死在程式碼中，實務可用 config 檔
